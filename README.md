# 🎵 ربات تلگرام دانلود از ساندکلاد (SoundCloud Downloader)

یک ربات تلگرامی ساده و کاربردی با پایتون برای دانلود آهنگ از ساندکلاد از طریق سرویس KlickAud و ارسال مستقیم فایل صوتی به چت تلگرام.

---

## 🚀 قابلیت‌ها
- دریافت لینک ساندکلاد و استخراج فایل صوتی با فرمت MP3
- دانلود مستقیم و ارسال به عنوان Audio در تلگرام
- استفاده از متغیر محیطی (Environment Variable) برای امنیت بالای توکن ربات

---

## 📋 پیش‌نیازها و نصب

ابتدا کتابخانه‌های مورد نیاز را با دستور زیر نصب کنید:

```bash
pip install -r requirements.txt
```

*(یا نصب دستی کتابخانه‌ها:)*
```bash
pip install python-telegram-bot requests beautifulsoup4
```

---

## ⚙️ راه‌اندازی و اجرا

### ۱. تنظیم توکن ربات در پاورشل (ویندوز)
قبل از اجرای ربات، توکن دریافتی از BotFather را در متغیر محیطی ست کنید:

```powershell
[Environment]::SetEnvironmentVariable("TELEGRAM_BOT_TOKEN", "YOUR_BOT_TOKEN", "User")
```

### ۲. اجرای پروژه
ترمینال را در پوشه پروژه باز کرده و دستور زیر را اجرا کنید:

```bash
python bot.py
```
